## API 通用规范

### 基本约定

| 项目 | 说明 |
|-----|------|
| **基础路径** | `/api` |
| **版本** | `v1`（可选：`/api/v1/...` 或统一使用 `/api/...`） |
| **数据格式** | JSON |
| **字符编码** | UTF-8 |
| **日期格式** | ISO 8601（`YYYY-MM-DDTHH:mm:ss`） |

### 统一响应格式

**成功响应（HTTP 200）：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    // 业务数据
  },
  "timestamp": "2024-01-20T10:30:00Z"
}
```

**分页响应：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [/* items */],
    "pageNo": 1,
    "pageSize": 10,
    "total": 100,
    "totalPages": 10
  },
  "timestamp": "2024-01-20T10:30:00Z"
}
```

**错误响应（HTTP 4xx/5xx）：**
```json
{
  "code": 1001,
  "message": "用户不存在或密码错误",
  "timestamp": "2024-01-20T10:30:00Z"
}
```

### 错误码定义

| 错误码 | HTTP 状态 | 说明 |
|-------|---------|------|
| 0 | 200 | 成功 |
| 1001 | 401 | 认证失败（用户名/密码错误、token过期等） |
| 1002 | 403 | 权限不足 |
| 1003 | 400 | 参数验证失败 |
| 1004 | 404 | 资源不存在 |
| 1005 | 409 | 业务冲突（如重复申请、重复收藏） |
| 1006 | 429 | 请求过于频繁（限流） |
| 1007 | 500 | 服务器错误 |

### 权限声明

所有接口中将标注所需权限：
- `无需认证`：游客可访问
- `需认证`：登录用户可访问
- `权限code`：需要特定权限（如 `pet:create`）

### 请求头要求

```
Authorization: Bearer <access_token>
Content-Type: application/json
```

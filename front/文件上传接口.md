## 宠物领养系统 - 文件上传接口文档

### 1. 接口概览

基础路径：`/api`

| 接口名称 | 请求方法 | 请求路径 | 功能描述 |
|---------|----------|----------|----------|
| 文件上传 | POST | `/upload` | 通用文件上传接口 |

---

### 2. 详细接口说明

#### 2.1 文件上传

- **接口地址**: `POST /api/upload`
- **功能描述**: 通用文件上传接口
- **请求头**: `Content-Type: multipart/form-data`
- **请求参数**:
  - `file` (MultipartFile, 必填): 要上传的文件
  - `type` (String, 必填): 文件类型标识，用于区分不同业务场景的文件上传

- **支持的文件类型**:
  - `avatar`: 用户头像
  - `pet_photo`: 宠物照片
  - `id_card`: 身份证照片
  - `license`: 营业执照
  - `other`: 其他文件

- **文件限制**:
  - 单个文件大小限制：10MB
  - 支持格式：jpg, jpeg, png, gif, pdf

- **请求示例**:
```javascript
// 使用 FormData 进行文件上传
const formData = new FormData();
formData.append('file', fileInput.files[0]);
formData.append('type', 'avatar');

fetch('/api/upload', {
  method: 'POST',
  body: formData
})
```


- **响应示例**:
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "url": "https://pet-adoption-system.oss-cn-beijing.aliyuncs.com/avatar/2024/12/19/uuid.jpg",
    "filename": "user_avatar.jpg",
    "size": 102400,
    "mime": "image/jpeg"
  },
  "timestamp": "2024-12-19 16:30:00"
}
```


- **响应参数说明**:
  - `url` (String): 文件访问URL
  - `filename` (String): 文件名
  - `size` (Long): 文件大小（字节）
  - `mime` (String): MIME类型

### 3. 前端调用示例

```javascript
// 文件上传函数
async function uploadFile(file, type) {
  const formData = new FormData();
  formData.append('file', file);
  formData.append('type', type);
  
  try {
    const response = await fetch('/api/upload', {
      method: 'POST',
      body: formData
    });
    
    const result = await response.json();
    if (result.code === 200) {
      return result.data;
    } else {
      throw new Error(result.message);
    }
  } catch (error) {
    console.error('文件上传失败:', error);
    throw error;
  }
}

// 使用示例
document.getElementById('fileInput').addEventListener('change', async function(event) {
  const file = event.target.files[0];
  if (file) {
    try {
      // 上传用户头像
      const uploadResult = await uploadFile(file, 'avatar');
      console.log('上传成功:', uploadResult);
      // 更新用户头像显示
      document.getElementById('avatarImg').src = uploadResult.url;
    } catch (error) {
      alert('上传失败: ' + error.message);
    }
  }
});

// React 组件示例
const FileUpload = ({ onUploadSuccess, fileType = 'other' }) => {
  const [uploading, setUploading] = useState(false);
  
  const handleFileChange = async (event) => {
    const file = event.target.files[0];
    if (!file) return;
    
    setUploading(true);
    try {
      const result = await uploadFile(file, fileType);
      onUploadSuccess(result);
    } catch (error) {
      console.error('上传失败:', error);
    } finally {
      setUploading(false);
    }
  };
  
  return (
    <div>
      <input 
        type="file" 
        onChange={handleFileChange} 
        accept="image/*,.pdf" 
        disabled={uploading}
      />
      {uploading && <span>上传中...</span>}
    </div>
  );
};
```

### 4. 错误处理

常见错误码及处理建议：

| 错误码 | 说明 | 前端处理建议 |
|--------|------|-------------|
| 400 | 请求参数错误 | 检查文件是否选择、type参数是否正确 |
| 413 | 文件过大 | 提示用户文件大小超过限制（10MB） |
| 415 | 不支持的文件类型 | 提示用户选择正确的文件格式 |
| 500 | 服务器内部错误 | 重试上传或联系管理员 |

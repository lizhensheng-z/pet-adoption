# 回访管理功能前后端对接文档（简化版）

## 功能概述

回访管理功能基于现有的领养申请和打卡记录实现，不新增任何表结构。机构用户通过查看已完成的领养申请和用户的打卡记录来进行回访管理。

## 基于现有数据结构

### 核心数据表
- `adoption_application` - 领养申请表
- `checkin_post` - 领养后打卡表
- `pet` - 宠物信息表
- `sys_user` - 用户信息表

### 回访提醒逻辑
基于领养申请的状态和时间计算回访提醒：
- 领养完成后30天：首次回访提醒
- 之后每90天：定期回访提醒
- 根据打卡记录判断回访状态

## API接口（仅使用现有接口）

### 1. 获取已领养宠物列表

**接口地址**: `GET /api/org/adoptions`

**请求参数**:
- `status` (string): 固定为 "APPROVED"
- `pageNo` (number): 页码，默认1
- `pageSize` (number): 每页条数，默认10

**响应示例**:

### 2. 获取用户打卡记录

**接口地址**: `GET /api/checkins`

**请求参数**:
- `petId` (number): 宠物ID
- `userId` (number): 用户ID
- `pageNo` (number): 页码
- `pageSize` (number): 每页条数

**接口地址**: `GET /api/org/adoption/applications/{applicationId}`

**接口地址**: `GET /api/org/adoptions`

## 前端实现调整

### 1. 回访提醒计算逻辑

基于现有数据计算回访状态：

```javascript
// 计算回访状态
const calculateFollowupStatus = (adoption) => {
  const adoptedDate = new Date(adoption.adoptedTime)
  const now = new Date()
  const daysSinceAdoption = Math.floor((now - adoptedDate) / (1000 * 60 * 60 * 24))
  
  if (daysSinceAdoption < 30) {
    return { status: 'WAITING', days: 30 - daysSinceAdoption }
  } else if (daysSinceAdoption < 90) {
    return { status: 'OVERDUE', days: daysSinceAdoption - 30 }
  } else {
    const cycle = Math.floor(daysSinceAdoption / 90)
    const nextFollowup = cycle * 90 + 30
    return { status: 'OVERDUE', days: daysSinceAdoption - nextFollowup }
  }
}
```

### 2. 回访操作实现

回访操作通过以下方式实现：

1. **查看领养详情**：通过现有接口获取申请详情
2. **查看打卡记录**：通过打卡接口了解宠物近况
3. **联系用户**：通过电话或微信联系（使用用户注册信息）
4. **记录回访**：在备注中记录回访情况（通过更新申请备注）

### 3. 简化后的页面功能

- **已领养宠物列表**：展示所有已批准的领养申请
- **回访状态计算**：基于领养时间计算回访状态
- **打卡记录查看**：查看用户的打卡记录了解宠物近况
- **联系方式**：直接显示用户注册的电话号码
- **手动记录**：通过更新申请备注记录回访情况

## 使用流程

### 1. 查看回访列表
- 进入"回访管理"页面
- 系统自动展示所有已领养宠物
- 根据领养时间计算回访状态

### 2. 执行回访
- 点击宠物查看详情
- 查看用户的打卡记录了解近况
- 通过电话联系用户
- 在申请备注中记录回访情况

### 3. 跟踪回访
- 定期查看打卡记录
- 根据打卡频率判断回访需求
- 手动维护回访计划

## 状态说明

### 回访状态（基于时间计算）
- **WAITING**: 领养后30天内，等待首次回访
- **OVERDUE**: 超过回访时间，需要回访
- **UPCOMING**: 即将到达回访时间
- **GOOD**: 用户打卡频繁，状态良好

### 回访周期
- 首次回访：领养后30天
- 定期回访：每90天一次
- 根据打卡情况调整回访频率

## 注意事项

1. **不新增任何表结构**：完全基于现有数据
2. **不存储回访记录**：通过现有字段记录回访情况
3. **手动维护回访计划**：通过计算和人工判断
4. **依赖用户行为**：通过打卡记录了解宠物状况
5. **简化操作流程**：减少系统复杂度

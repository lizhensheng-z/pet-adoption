### 2. 机构资料管理

#### 2.1 机构资料字段映射
根据后端接口，机构资料包含以下字段：

| 前端字段 | 后端字段 | 类型 | 必填 | 说明 |
|----------|----------|------|------|------|
| orgName | orgName | String | ✅ | 机构名称 |
| licenseNo | licenseNo | String | ✅ | 营业执照号 |
| contactName | contactName | String | ✅ | 联系人姓名 |
| contactPhone | contactPhone | String | ✅ | 联系电话 |
| address | address | String | ✅ | 详细地址 |
| province | province | String | ❌ | 省份 |
| city | city | String | ❌ | 城市 |
| district | district | String | ❌ | 区县 |
| lng | lng | Number | ❌ | 经度 |
| lat | lat | Number | ❌ | 纬度 |
| coverUrl | coverUrl | String | ❌ | 机构封面图 |

#### 2.2 机构类型枚举
与后端保持一致：
- RESCUE: 救助站
- HOSPITAL: 宠物医院
- PET_SHOP: 宠物店
- CHARITY: 公益组织
- OTHER: 其他

### 3. 状态管理

#### 3.1 机构状态流转
- **PENDING**: 待审核（默认状态）
- **APPROVED**: 审核通过
- **REJECTED**: 审核拒绝

#### 3.2 状态对应的权限
| 状态 | 功能权限 | 页面访问 |
|------|----------|----------|
| PENDING | 只能完善资料 | 限制访问机构功能页面 |
| APPROVED | 全部功能 | 正常访问 |
| REJECTED | 只能修改资料 | 强制跳转到资料修改页 |

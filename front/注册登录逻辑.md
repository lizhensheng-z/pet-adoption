## 📋 机构用户注册和登录状态处理完整方案

### 1. 机构注册流程优化

**当前状态：**
- 用户表(`sys_user`)：存储用户基本信息，包含角色字段
- 机构资料表(`org_profile`)：存储机构详细信息，包含认证状态字段

### 2. 优化后的注册流程

#### 2.1 注册流程设计

**注册步骤：**
1. 用户选择注册为机构角色
2. 填写基本信息（用户名、密码）
3. 填写机构详细信息（机构名称、联系人、电话等）
4. 创建用户记录，角色为"ORG"
5. 创建机构资料记录，认证状态为"PENDING"

#### 2.2 注册接口实现

**注册接口：**
```javascript
// 机构注册接口
POST /api/auth/register/org
```

**请求数据：**
```json
{
  "username": "救助中心001",
  "password": "******",
  "role": "ORG",
  "orgName": "爱心救助中心",
  "contactName": "张小明",
  "contactPhone": "13800138000",
  "email": "contact@example.com",
  "licenseNo": "BJ2024001",
  "address": "北京市朝阳区xxx路xxx号"
}
```

**后端处理：**
```java
@Transactional
public UserEntity registerOrgUser(RegisterOrgRequest request) {
    // 1. 创建用户
    UserEntity user = new UserEntity();
    user.setUsername(request.getUsername());
    user.setPassword(passwordEncoder.encode(request.getPassword()));
    user.setRole("ORG");
    user.setStatus("NORMAL");
    user.setEmail(request.getEmail());
    user.setPhone(request.getContactPhone());
    userMapper.insert(user);
    
    // 2. 创建机构资料
    OrgProfileEntity orgProfile = new OrgProfileEntity();
    orgProfile.setUserId(user.getId());
    orgProfile.setOrgName(request.getOrgName());
    orgProfile.setContactName(request.getContactName());
    orgProfile.setContactPhone(request.getContactPhone());
    orgProfile.setLicenseNo(request.getLicenseNo());
    orgProfile.setAddress(request.getAddress());
    orgProfile.setVerifyStatus("PENDING");
    orgProfile.setDeleted(0);
    orgProfileMapper.insert(orgProfile);
    
    return user;
}
```

### 3. 登录状态检查机制

#### 3.1 登录响应增强
**登录接口：** `POST /api/auth/login`

**响应数据：**
```json
{
  "code": 10000,
  "data": {
    "token": "xxx",
    "user": {
      "id": 123,
      "username": "救助中心001",
      "role": "ORG",
      "orgStatus": "PENDING",
      "orgProfileComplete": true,
      "permissions": ["org:profile:read", "org:profile:update"]
    }
  }
}
```

#### 3.2 状态处理规则

| 机构状态 | 登录处理 | 功能限制 | 前端提示 |
|----------|----------|----------|----------|
| PENDING | 允许登录 | 只能查看个人资料，不能发布宠物 | 显示"机构审核中" |
| APPROVED | 允许登录 | 全部功能 | 正常操作 |
| REJECTED | 允许登录 | 只能修改资料 | 显示"资料被拒绝，请重新提交" |

### 4. 前端路由守卫实现

#### 4.1 路由守卫配置
```javascript
// 路由守卫检查机构状态
router.beforeEach((to, from, next) => {
  const user = store.getters.user;
  
  if (user?.role === 'ORG') {
    const status = user.orgStatus;
    
    // 未完善资料且访问非资料页面
    if (!user.orgProfileComplete && !to.path.startsWith('/org/profile')) {
      next('/org/profile');
      return;
    }
    
    // 根据状态限制访问
    switch (status) {
      case 'PENDING':
        if (to.path.startsWith('/org/pets') || to.path.startsWith('/org/applications')) {
          ElMessage.warning('机构审核中，暂无法使用此功能');
          next('/org/waiting');
          return;
        }
        break;
      case 'REJECTED':
        if (!to.path.startsWith('/org/profile')) {
          ElMessage.warning('请先完善机构资料');
          next('/org/profile/rejected');
          return;
        }
        break;
    }
  }
  
  next();
});
```

### 5. 前端状态提示组件

#### 5.1 机构状态提示组件
```vue
<!-- 机构状态提示组件 -->
<template>
  <el-alert
    :title="statusInfo.title"
    :type="statusInfo.type"
    :description="statusInfo.message"
    show-icon
    :closable="false"
    class="mb-4"
  />
</template>

<script setup>
import { computed } from 'vue'
import { useStore } from 'vuex'

const store = useStore()

const statusInfo = computed(() => {
  const user = store.getters.user
  if (user?.role !== 'ORG') return {}
  
  const map = {
    'PENDING': { 
      type: 'warning', 
      title: '机构审核中', 
      message: '您的机构资料正在审核中，请耐心等待。审核通过后即可发布宠物信息。' 
    },
    'APPROVED': { 
      type: 'success', 
      title: '机构已认证', 
      message: '恭喜！您的机构已通过认证，可以正常使用所有功能。' 
    },
    'REJECTED': { 
      type: 'error', 
      title: '机构认证被拒绝', 
      message: '您的机构资料被拒绝，请根据反馈修改后重新提交。' 
    }
  }
  
  return map[user.orgStatus] || {}
})
</script>
```

### 6. 机构资料完善页面

#### 6.1 机构资料完善表单
```vue
<template>
  <div class="org-profile-container">
    <el-card>
      <template #header>
        <div class="card-header">
          <span>机构资料完善</span>
          <el-tag :type="statusTagType">{{ statusText }}</el-tag>
        </div>
      </template>
      
      <el-form :model="form" :rules="rules" ref="formRef" label-width="120px">
        <el-form-item label="机构名称" prop="orgName">
          <el-input v-model="form.orgName" placeholder="请输入机构名称" />
        </el-form-item>
        
        <el-form-item label="联系人姓名" prop="contactName">
          <el-input v-model="form.contactName" placeholder="请输入联系人姓名" />
        </el-form-item>
        
        <el-form-item label="联系电话" prop="contactPhone">
          <el-input v-model="form.contactPhone" placeholder="请输入联系电话" />
        </el-form-item>
        
        <el-form-item label="机构资质号" prop="licenseNo">
          <el-input v-model="form.licenseNo" placeholder="请输入机构资质号" />
        </el-form-item>
        
        <el-form-item label="详细地址" prop="address">
          <el-input v-model="form.address" type="textarea" placeholder="请输入详细地址" />
        </el-form-item>
        
        <el-form-item>
          <el-button type="primary" @click="submitForm" :loading="submitting">
            提交审核
          </el-button>
        </el-form-item>
      </el-form>
    </el-card>
  </div>
</template>

<script setup>
import { ref, reactive, onMounted } from 'vue'
import { useStore } from 'vuex'
import { ElMessage } from 'element-plus'

const store = useStore()
const formRef = ref()
const submitting = ref(false)

const form = reactive({
  orgName: '',
  contactName: '',
  contactPhone: '',
  licenseNo: '',
  address: ''
})

const rules = {
  orgName: [{ required: true, message: '请输入机构名称', trigger: 'blur' }],
  contactName: [{ required: true, message: '请输入联系人姓名', trigger: 'blur' }],
  contactPhone: [
    { required: true, message: '请输入联系电话', trigger: 'blur' },
    { pattern: /^1[3-9]\d{9}$/, message: '请输入正确的手机号', trigger: 'blur' }
  ],
  licenseNo: [{ required: true, message: '请输入机构资质号', trigger: 'blur' }],
  address: [{ required: true, message: '请输入详细地址', trigger: 'blur' }]
}

const submitForm = async () => {
  try {
    await formRef.value.validate()
    submitting.value = true
    
    await orgAPI.updateOrgProfile(form)
    ElMessage.success('提交成功，请等待审核')
    
    // 刷新用户信息
    await store.dispatch('user/getUserInfo')
  } catch (error) {
    ElMessage.error('提交失败')
  } finally {
    submitting.value = false
  }
}

// 加载现有资料
onMounted(async () => {
  const user = store.getters.user
  if (user?.role === 'ORG') {
    const profile = await orgAPI.getOrgProfile()
    Object.assign(form, profile.data)
  }
})
</script>
```

### 7. 总结

**机构用户注册登录流程总结：**

```
注册机构用户 → 完善机构资料 → 等待审核 → 审核通过 → 正常使用
                     ↓
                 审核拒绝 → 修改资料 → 重新提交
```

- 状态控制严格准确
- 用户体验友好
- 权限控制清晰
- 数据完整性保证

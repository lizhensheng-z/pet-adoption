## 宠物领养系统 - 机构管理接口文档

### 1. 接口概览

基础路径：`/api/org`

| 接口名称 | 请求方法 | 请求路径 | 功能描述 | 权限要求 |
|---------|----------|----------|----------|----------|
| 获取机构资料 | GET | `/profile` | 获取当前机构的详细资料信息 | `org:profile:read` |
| 更新机构资料 | PUT | `/profile` | 更新机构资料信息 | `org:profile:update` |
| 获取机构统计数据 | GET | `/statistics` | 获取机构的各项统计数据 | `org:statistics:read` |
| 获取领养完成记录 | GET | `/adoptions` | 获取机构的领养完成记录列表 | `org:adoptions:read` |
| 获取回访提醒 | GET | `/followup-reminders` | 获取需要回访的提醒信息 | `org:followup:read` |

---

### 2. 详细接口说明

#### 2.1 获取机构资料

- **接口地址**: `GET /api/org/profile`
- **功能描述**: 获取当前机构的详细资料信息
- **权限要求**: `org:profile:read`
- **请求头**: `Authorization: Bearer {access_token}`
- **请求参数**: 无

- **响应示例**:
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "id": 1,
    "userId": 1001,
    "orgName": "爱心宠物救助中心",
    "licenseNo": "91110108MA01XXXXXX",
    "contactName": "张三",
    "contactPhone": "13800138000",
    "address": "北京市朝阳区XXX街道",
    "province": "北京市",
    "city": "北京市",
    "district": "朝阳区",
    "lng": 116.4074,
    "lat": 39.9042,
    "verifyStatus": "APPROVED",
    "verifyRemark": "审核通过",
    "createTime": "2024-01-01T10:00:00",
    "updateTime": "2024-12-19T15:30:00"
  },
  "timestamp": "2024-12-19 15:30:00"
}
```


- **响应参数说明**:
  - `id` (Long): 机构资料ID
  - `userId` (Long): 关联的用户ID
  - `orgName` (String): 机构名称
  - `licenseNo` (String): 营业执照编号
  - `contactName` (String): 联系人姓名
  - `contactPhone` (String): 联系电话
  - `address` (String): 详细地址
  - `province` (String): 省份
  - `city` (String): 城市
  - `district` (String): 区县
  - `lng` (BigDecimal): 经度
  - `lat` (BigDecimal): 纬度
  - `verifyStatus` (String): 审核状态（PENDING/APPROVED/REJECTED）
  - `verifyRemark` (String): 审核备注
  - `createTime` (LocalDateTime): 创建时间
  - `updateTime` (LocalDateTime): 更新时间

---

#### 2.2 更新机构资料

- **接口地址**: `PUT /api/org/profile`
- **功能描述**: 更新机构资料信息
- **权限要求**: `org:profile:update`
- **请求头**: 
  - `Content-Type: application/json`
  - `Authorization: Bearer {access_token}`
- **请求体**:
```json
{
  "orgName": "爱心宠物救助中心",
  "licenseNo": "91110108MA01XXXXXX",
  "contactName": "张三",
  "contactPhone": "13800138000",
  "address": "北京市朝阳区XXX街道",
  "province": "北京市",
  "city": "北京市",
  "district": "朝阳区",
  "lng": 116.4074,
  "lat": 39.9042
}
```


- **请求参数说明**:
  - `orgName` (String, 必填): 机构名称
  - `licenseNo` (String, 可选): 营业执照编号
  - `contactName` (String, 必填): 联系人姓名
  - `contactPhone` (String, 可选): 联系电话（支持手机号或座机号格式）
  - `address` (String, 可选): 详细地址
  - `province` (String, 可选): 省份
  - `city` (String, 可选): 城市
  - `district` (String, 可选): 区县
  - `lng` (BigDecimal, 可选): 经度
  - `lat` (BigDecimal, 可选): 纬度

- **响应示例**:
```json
{
  "code": 200,
  "message": "操作成功",
  "data": null,
  "timestamp": "2024-12-19 15:30:00"
}
```

#### 2.4 获取领养完成记录

- **接口地址**: `GET /api/org/adoptions`
- **功能描述**: 获取机构的领养完成记录列表
- **权限要求**: `org:adoptions:read`
- **请求头**: `Authorization: Bearer {access_token}`
- **请求参数**:
  - `petId` (Long, 可选): 宠物ID，用于筛选特定宠物的记录
  - `userId` (Long, 可选): 用户ID，用于筛选特定用户的记录
  - `month` (String, 可选): 月份，格式为"YYYY-MM"，用于筛选特定月份的记录
  - `pageNo` (Integer, 可选): 页码，默认为1
  - `pageSize` (Integer, 可选): 每页数量，默认为10
  - `sortBy` (String, 可选): 排序字段，默认为"adoptedTime"
  - `order` (String, 可选): 排序方式，默认为"desc"

- **请求示例**:
```
GET /api/org/adoptions?petId=1&month=2024-12&pageNo=1&pageSize=10
```


- **响应示例**:
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "list": [
      {
        "id": 1,
        "petId": 1,
        "petName": "小白",
        "userId": 1001,
        "userName": "user_1001",
        "userPhone": "138****0000",
        "userCredit": {
          "score": 85,
          "level": "B"
        },
        "adoptedTime": "2024-12-01T10:00:00",
        "daysSinceAdoption": 18,
        "checkinCount": 15,
        "checkinRate": 0.83,
        "userStatus": "正常",
        "riskLevel": "低"
      }
    ],
    "pageNo": 1,
    "pageSize": 10,
    "total": 25,
    "totalPages": 3
  },
  "timestamp": "2024-12-19 15:30:00"
}
```


- **响应参数说明**:
  - `list` (Array): 领养记录列表
    - `id` (Long): 记录ID
    - `petId` (Long): 宠物ID
    - `petName` (String): 宠物名称
    - `userId` (Long): 用户ID
    - `userName` (String): 用户名
    - `userPhone` (String): 用户手机号（已脱敏）
    - `userCredit` (Object): 用户信用信息
      - `score` (Integer): 信用分
      - `level` (String): 信用等级
    - `adoptedTime` (LocalDateTime): 领养时间
    - `daysSinceAdoption` (Integer): 领养天数
    - `checkinCount` (Integer): 打卡次数
    - `checkinRate` (Double): 打卡率
    - `userStatus` (String): 用户状态
    - `riskLevel` (String): 风险等级
  - `pageNo` (Integer): 当前页码
  - `pageSize` (Integer): 每页数量
  - `total` (Long): 总记录数
  - `totalPages` (Integer): 总页数

#### 2.5 获取回访提醒

- **接口地址**: `GET /api/org/followup-reminders`
- **功能描述**: 获取需要回访的提醒信息
- **权限要求**: `org:followup:read`
- **请求头**: `Authorization: Bearer {access_token}`
- **请求参数**: 无

- **响应示例**:
```json
{
  "code": 200,
  "message": "操作成功",
  "data": {
    "overdue": [
      {
        "petId": 1,
        "petName": "小白",
        "userId": 1001,
        "userName": "user_1001",
        "adoptedTime": "2024-09-01T10:00:00",
        "daysSinceAdoption": 110,
        "expectedCheckinDay": 90,
        "isOverdue": true,
        "daysRemaining": null,
        "riskLevel": "中"
      }
    ],
    "upcoming": [
      {
        "petId": 2,
        "petName": "小黑",
        "userId": 1002,
        "userName": "user_1002",
        "adoptedTime": "2024-12-15T10:00:00",
        "daysSinceAdoption": 4,
        "expectedCheckinDay": 7,
        "isOverdue": false,
        "daysRemaining": 3,
        "riskLevel": "低"
      }
    ]
  },
  "timestamp": "2024-12-19 15:30:00"
}
```


- **响应参数说明**:
  - `overdue` (Array): 已逾期的回访提醒
  - `upcoming` (Array): 即将到期的回访提醒
  - 每个提醒项包含:
    - `petId` (Long): 宠物ID
    - `petName` (String): 宠物名称
    - `userId` (Long): 用户ID
    - `userName` (String): 用户名
    - `adoptedTime` (LocalDateTime): 领养时间
    - `daysSinceAdoption` (Integer): 领养天数
    - `expectedCheckinDay` (Integer): 预期打卡天数
    - `isOverdue` (Boolean): 是否已逾期
    - `daysRemaining` (Integer): 剩余天数
    - `riskLevel` (String): 风险等级

---

### 3. 公共响应结构

所有接口均返回统一的响应格式：

```json
{
  "code": 200,
  "message": "操作成功",
  "data": {},
  "timestamp": "2024-12-19 15:30:00"
}
```


- `code` (Integer): 状态码，200表示成功
- `message` (String): 响应消息
- `data` (Object): 返回的数据，可能为空
- `timestamp` (String): 时间戳

---

### 4. 错误码说明

| 错误码 | 说明 |
|--------|------|
| 200 | 操作成功 |
| 400 | 请求参数错误 |
| 401 | 未授权 |
| 403 | 禁止访问（权限不足） |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

### 5. 前端调用示例

```javascript
// 获取机构资料
async function getOrgProfile() {
  const accessToken = localStorage.getItem('accessToken');
  const response = await fetch('/api/org/profile', {
    headers: {
      'Authorization': `Bearer ${accessToken}`
    }
  });
  
  const result = await response.json();
  if (result.code === 200) {
    return result.data;
  } else {
    throw new Error(result.message);
  }
}

// 更新机构资料
async function updateOrgProfile(profileData) {
  const accessToken = localStorage.getItem('accessToken');
  const response = await fetch('/api/org/profile', {
    method: 'PUT',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${accessToken}`
    },
    body: JSON.stringify(profileData)
  });
  
  const result = await response.json();
  if (result.code !== 200) {
    throw new Error(result.message);
  }
}

// 获取领养记录列表
async function getAdoptionRecords(params = {}) {
  const accessToken = localStorage.getItem('accessToken');
  const queryParams = new URLSearchParams(params).toString();
  const response = await fetch(`/api/org/adoptions?${queryParams}`, {
    headers: {
      'Authorization': `Bearer ${accessToken}`
    }
  });
  
  const result = await response.json();
  if (result.code === 200) {
    return result.data;
  } else {
    throw new Error(result.message);
  }
}
```

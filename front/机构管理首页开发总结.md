## 功能概览

机构管理首页（Dashboard）是机构用户登录后的第一个页面，提供关键数据统计、待办事项提醒、快捷操作入口等功能，帮助机构用户快速了解工作状态和进行日常操作。

## 功能模块详解

### 1. 统计卡片模块 (StatCard.vue)

**功能描述**：
- 显示关键业务指标
- 支持点击跳转到相应功能页面
- 支持趋势显示（上升/下降/持平）

**统计数据**：
- 在养宠物数 (totalPets)
- 待处理申请数 (pendingApplications)
- 本月领养数 (monthlyAdoptions)
- 待回访数 (pendingFollowups)

**组件特点**：
- 渐变色图标背景
- 响应式布局（移动端/PC端适配）
- 悬停动画效果
- 支持趋势指示器

**API接口**：
- `/api/org/dashboard/statistics` - 获取统计数据
- `/api/org/dashboard/home` - 获取综合数据（推荐）

---

### 2. 快捷操作模块 (QuickActions.vue)

**功能描述**：
- 提供常用功能的快速入口
- 彩色渐变图标设计
- 清晰的操作描述

**快捷操作**：
- 宠物管理 → 跳转到 `/org/pets`
- 申请管理 → 跳转到 `/org/applications`
- 回访管理 → 跳转到 `/org/followup`
- 统计数据 → 跳转到 `/org/statistics`

**设计特点**：
- 2x2 网格布局
- 悬停时图标轻微上移
- 右侧箭头动画提示

---

### 3. 待办事项模块

#### 3.1 待办事项单项 (DashboardTodoItem.vue)

**功能描述**：
- 展示单个待办事项的详细信息
- 根据优先级显示不同颜色标识
- 支持点击跳转到详情页

**待办类型**：
- `application` - 领养申请待审核
- `followup` - 回访提醒
- `audit` - 宠物发布待审核

**优先级映射**：
- `urgent` (紧急) - 红色标识
- `high` (高) - 橙色标识
- `medium` (中) - 绿色标识
- `low` (低) - 灰色标识

**显示内容**：
- 待办标题
- 待办类型标签
- 提交时间（相对时间显示）
- 申请人/宠物信息（根据类型）
- 超期天数（回访类型）

#### 3.2 待办事项列表 (DashboardTodoList.vue)

**功能描述**：
- 管理和展示待办事项列表
- 支持按类型筛选
- 支持加载更多
- 显示待办总数

**筛选选项**：
- 全部
- 申请
- 回访
- 审核

**交互功能**：
- 类型筛选
- 查看全部按钮
- 加载更多功能

**API接口**：
- `/api/org/dashboard/todos` - 获取待办事项列表
- `/api/org/dashboard/home` - 获取综合数据（推荐）

---

### 4. 最近宠物模块 (DashboardRecentPets.vue)

**功能描述**：

- 宠物名称和品种
- 年龄和性别

- 状态标签（已发布/申请中/已领养等）
- 统计数据（浏览/收藏/申请次数）

**布局特点**：
- 响应式网格布局
- PC端4列，移动端2列
- 图片1:1宽高比
- 悬停时卡片上浮效果

**API接口**：
- `/api/org/pets/recent` - 获取最近宠物列表
- `/api/org/dashboard/home` - 获取综合数据（推荐）

---

### 5. 最近申请模块 (DashboardRecentApplications.vue)

**功能描述**：
- 展示最新的领养申请
- 申请卡片列表形式
- 支持点击处理申请

**显示信息**：
- 申请人头像和姓名
- 宠物封面图片
- 申请状态标签
- 申请时间（相对时间显示）

**状态映射**：
- `SUBMITTED` - 已提交
- `UNDER_REVIEW` - 审核中
- `INTERVIEW` - 已约面谈
- `HOME_VISIT` - 家访中
- `APPROVED` - 已通过
- `REJECTED` - 已拒绝
- `CANCELLED` - 已取消

**交互功能**：
- 点击跳转到申请详情页
- 处理按钮快速操作

**API接口**：
- `/api/org/applications/recent` - 获取最近申请列表
- `/api/org/dashboard/home` - 获取综合数据（推荐）

---

### 6. 主页面组件 (Dashboard.vue)

**功能描述**：
- 整合所有子组件
- 管理数据加载和状态
- 权限检查和路由跳转
- 自动刷新机制

**核心功能**：
- 权限验证（org:access）
- 数据加载（优先使用综合接口）
- 降级加载机制
- 自动刷新（5分钟间隔）
- 手动刷新功能

**数据流**：
```
1. 页面加载
2. 检查权限
3. 调用 getDashboardHome() 接口
4. 解析数据并更新各个子组件
5. 启动定时刷新
```

**降级机制**：
如果综合接口失败，自动降级为单独接口：
- `getDashboardStatistics()` - 统计数据
- `getDashboardTodos()` - 待办事项
- `getRecentPets()` - 最近宠物
- `getRecentApplications()` - 最近申请

## 部署注意事项

### 1. 环境变量
确保 `.env` 文件中配置正确的 API 地址：
```bash
VITE_API_BASE_URL=/api
```

### 2. 权限配置
确保用户具有 `org:access` 权限才能访问首页

确保路由正确配置在 `src/router/org.js` 中
